# 자산 검수 진행표

검수조서 PDF 또는 이미지에서 주요 정보를 읽어 검수 건을 등록하고, 필요한 납품서류·서명·후속 업무의 진행 상태를 한 화면에서 관리하는 웹앱입니다.

## 사용 방법

1. `검수 건 추가`를 누릅니다.
2. 검수조서 PDF/이미지를 선택하거나 내용을 직접 입력합니다.
3. 접수한 서류, 서명 여부, 메일 발송과 관리대장 기록 상태를 체크합니다.
4. 검색창과 진행상태 필터로 필요한 검수 건을 찾습니다.

입력한 내용은 서버가 아니라 현재 사용 중인 브라우저의 `localStorage`에만 저장됩니다. 따라서 다른 기기나 다른 브라우저에는 자동으로 공유되지 않으며, 브라우저 데이터를 지우면 함께 삭제될 수 있습니다.

## GitHub Pages

이 저장소는 별도의 빌드 과정 없이 GitHub Pages에서 바로 공개할 수 있는 정적 웹사이트입니다. GitHub 저장소의 Pages 설정에서 배포할 브랜치와 루트(`/`) 폴더를 선택하면 됩니다.
